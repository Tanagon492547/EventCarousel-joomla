"# EventCarousel-joomla" 

###### สำหรับ mod_event_carousel เป็น Module ของ joomla โดยพัฒนาจาก joomla 5 โดยเฉพาะ

## วิธีนำไปใช้
*ให้ เลือกไฟล์ mod_event_carousel.zip ไปใส่ในเว็บไซต์  joomla ของคุณ*

## Filed ที่ใช้
*เรามาทำความรู้จัก filed ที่ใช้ ใน module นี้กัน ว่ามีอะไรบ้าง*

| Filed  | คำอธิบาย | ประเภท |
| ------------- |:-------------:|:-------------:|
| sources-funding      | รายละเอียด เเหล่งที่มาของกองทุน     | text |
| scholarship-name     | ชื่อทุน     | text |
| open-day      | วันที่เปิดรับ     | calendar |
| close-date     | วันที่ปิดรับ     | calendar |
| scholarships-image      | รูปภาพทุน     | media |
| scholarships-url      | ลิงค์ที่ต้องการให้เข้าชมทุน     | url |
